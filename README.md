# Тренировка таза — Telegram Mini App

Личное приложение для комплекса при hEDS/HSD (правосторонняя дисфункция таза).
Без базы данных и сервера: статика на Vite + TypeScript, прогресс хранится в
**Telegram CloudStorage** (синхронизируется между устройствами), а в обычном
браузере — в `localStorage`.

## Что умеет

- **Последовательное прохождение** всех 5 блоков и 18 упражнений в правильном
  порядке, с полным описанием и техническими подсказками из исходного комплекса.
- **Таймер с озвучкой для каждого упражнения** — нажми «Старт» и работай не глядя
  на экран:
  - звуковой сигнал на старте удержания/повтора, тики по секундам;
  - голос по-русски считает повторы («раз, два, три…»), объявляет подходы,
    смену стороны и отдых;
  - обратный отсчёт «3-2-1» перед удержаниями;
  - удержания (8 сек, 30 сек), темповые повторы (3 сек вверх / 3 сек вниз),
    дыхательные циклы 4/6 — всё запрограммировано по тексту комплекса.
- **Учёт 2× в день**: главный экран показывает слоты «Утро/Вечер», серию дней
  подряд, сколько из последних 30 дней выполнены по 2 раза, и календарь за 14 дней.
- Тумблеры «Сигналы» и «Голос», пауза и «пропустить шаг».
- Принципы и предостережения из комплекса (когда НЕ тренироваться и т. п.).

> Слот считается «Утро», если запуск до 14:00, иначе «Вечер». Полная тренировка
> засчитывается, когда завершено последнее упражнение (5.2).

## Запуск локально

```bash
npm install
npm run dev      # http://localhost:5173 — откроется в браузере (fallback на localStorage)
npm run build    # сборка в dist/
npm run preview  # предпросмотр собранной версии
```

В обычном браузере нет Telegram, поэтому тема дефолтная и прогресс пишется в
`localStorage` — этого достаточно для проверки логики и звуков.

## Деплой (бесплатно)

Любой статический хостинг по HTTPS. Vite собран с `base: "./"`, поэтому работает
из любой под-папки.

**GitHub Pages:**
```bash
npm run build
# Закоммить содержимое dist/ в ветку gh-pages (или используй actions),
# либо подними любой статик-хостинг.
```

**Netlify / Cloudflare Pages / Vercel:** подключи репозиторий, команда сборки
`npm run build`, каталог публикации `dist`.

Telegram требует **HTTPS** для mini app — `http://localhost` подходит только для
теста в браузере, но не как кнопка в боте.

## Подключение к боту (BotFather)

1. Создай бота: напиши [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Привяжи URL приложения:
   - `/newapp` → выбери бота → задай название, описание, иконку → **Web App URL**
     укажи адрес задеплоенной страницы (например, `https://username.github.io/sport_app/`).
   - либо `/setmenubutton` → выбери бота → пришли тот же URL, чтобы кнопка меню
     рядом с полем ввода открывала приложение.
3. Открой бота, нажми кнопку меню — приложение запустится внутри Telegram, тема
   подхватится автоматически, прогресс будет в CloudStorage.

## Замечания по звуку

- На телефоне звук «разблокируется» только после касания — поэтому первый
  сигнал идёт по нажатию «Старт» (это требование iOS/Android).
- Голос использует системный синтез речи (`ru-RU`). Если в системе нет русского
  голоса, озвучка повторов может звучать на голосе по умолчанию — тики/сигналы
  всё равно работают. Голос можно выключить тумблером «Голос», оставив сигналы.

## Структура

| Файл | Назначение |
|---|---|
| `src/types.ts` | Модель данных комплекса и записей тренировок |
| `src/workout.ts` | Сам комплекс (5 блоков, 18 упражнений) — дословно из `complex.md` |
| `src/engine.ts` | Разворачивает упражнение в таймлайн фаз и проигрывает его |
| `src/audio.ts` | Сигналы (WebAudio) + русская озвучка (SpeechSynthesis) |
| `src/tracking.ts` | Слоты, серия, календарь, «идеальные» дни |
| `src/telegram.ts` | Обёртка над Telegram WebApp SDK + хранилище |
| `src/main.ts` | Экраны и навигация |

## Дисклеймер

Это не медицинская рекомендация. Комплекс взят из `complex.md`. При боли, хрусте
или симптомах со стороны шеи — остановиться (см. экран «Принципы и
предостережения»).
